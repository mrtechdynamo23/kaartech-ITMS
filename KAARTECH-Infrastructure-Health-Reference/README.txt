KAARTECH ITMS — Infrastructure Health Reference

Purpose:
This package contains the Infrastructure Health-related source extracted from the
NCGR portal for use as a FUNCTIONAL REFERENCE when integrating Infrastructure
Health into the KAARTECH ITMS portal.

Important:
- Do not merge the NCGR application wholesale.
- Adapt the functionality to the existing KAARTECH ITMS architecture and UI.
- Remove/replace NCGR-specific branding, client data, routes, locations, and identifiers.
- Reuse the infrastructure concepts, data model, health KPIs, filters, tables,
  detail views, and relevant sub-page behavior as applicable.
- Prefer the newer Infrastructure Health implementation over duplicate/legacy
  infrastructure implementations.
- Do not treat the included package/config files as instructions to replace the
  KAARTECH project's dependencies or architecture.

This is a reference package, not a standalone production application.
