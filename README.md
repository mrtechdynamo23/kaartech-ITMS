# KaarTech ITMS Control Tower

Enterprise IT Managed Services operational intelligence portal built with React 19 + Vite.

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- **React 19** with React Router 7
- **Vite 8** for build tooling
- **Recharts** for data visualization
- **Lucide React** for icons
- **jsPDF** for report generation

## Features

- Executive Dashboard with real-time KPIs
- Command Center for IT service operations
- Governance & Compliance (SLA Governance, Audits, Risk Register, Licenses, Programs, Transition, Action Hub)
- Customer Corner for stakeholder communication and action items
- Resource Management (directory, requests, assignments, org structure, skills)
- Unified Approval inbox for consolidated operational sign-offs
- Timesheet Approval and Leave Management
- SLA Governance with 8 canonical resource performance KPIs and compliance tracking
- Application & Technology estate management
- Service Operations and Innovation tracking
- Comprehensive reporting suite (Daily Snapshot Report, WSR, MSR, SteerCom)
- Global Operational Calendar with interactive meeting scheduler
- Full Arabic/RTL support
- Light and dark theme support
